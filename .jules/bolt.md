## 2026-09-03 - Optimize SQLAlchemy Keyset Pagination\n**Learning:** Hydrating full SQLAlchemy entities during keyset pagination (via `.first()`) can be slow if models have large text fields. Fetching only the specific cursor value (like `created_at`) using `.scalar()` avoids this overhead. Additionally, the composite index to support this must strictly match the `order_by` clause and must be placed at the end of the class in `__table_args__` after the referenced columns are defined.\n**Action:** Use `.scalar()` to fetch specific cursor values for pagination instead of loading the full entity, and always place `__table_args__` at the end of the SQLAlchemy model class to prevent undefined references to columns.
