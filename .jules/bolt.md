## 2024-05-24 - Keyset Pagination requires DB Indexes
**Learning:** The `read_grievances` API uses keyset pagination sorting on `created_at`. Without an index on `created_at`, the database will execute an O(N log N) full table sort for every API fetch, becoming a major performance bottleneck for a public feed.
**Action:** When implementing keyset pagination or sorting by a column, ensure `index=True` is set in the SQLAlchemy model AND a corresponding `CREATE INDEX` statement is added to the raw SQL schema files.
