## 2026-07-18 - Keyset Pagination Optimization
**Learning:** Keyset pagination queries that sort by multiple columns (e.g., `created_at DESC, id DESC`) require an explicit composite database index. Adding `index=True` to a single column is insufficient for fully optimizing multi-column sorts.
**Action:** Always create composite indexes like `Index('name', col1.desc(), col2.desc())` in `__table_args__` when implementing keyset pagination.
