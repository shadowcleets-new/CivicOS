## 2024-07-06 - Keyset Pagination Indexing
**Learning:** Keyset pagination queries that sort by multiple columns (e.g., `created_at DESC, id DESC`) require an explicit composite database index in the raw SQL schema to optimize. Modifying the SQLAlchemy model definition alone is insufficient. When testing endpoints that sort by `created_at` and a UUID, bulk inserting test records will create identical timestamps leading to non-deterministic ordering, requiring unique timestamps during test data generation.
**Action:** Always add a composite database index in the raw SQL schema and add unique timestamps to test data when implementing or testing keyset pagination.
