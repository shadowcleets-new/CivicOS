## 2024-05-24 - Database Indexes for Keyset Pagination
**Learning:** When using keyset/cursor pagination on an endpoint, sorting by a column like `created_at` without a database index will result in full table scans and slow sort operations, causing poor performance on large datasets.
**Action:** Always ensure that columns used for sorting in cursor pagination have a database index (e.g., `index=True` in SQLAlchemy) to enable fast keyset seek operations.
