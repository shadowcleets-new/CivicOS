## 2024-07-12 - Adding Composite Indexes for Keyset Pagination
**Learning:** Keyset pagination queries that sort by multiple columns (e.g., `created_at DESC, id DESC`) require an explicit composite database index in the raw SQL schema to be fully optimized. Simply adding `index=True` to single SQLAlchemy columns does not optimize multi-column sorting. Additionally, bulk inserting records during testing can result in identical timestamps, leading to non-deterministic ordering and flaky tests when sorted by descending timestamps and random UUIDs.
**Action:** Always use `__table_args__` with an explicit `Index` definition for multi-column sorts (e.g., `Index('idx_name', text('col1 DESC'), text('col2 DESC'))`), and ensure unique timestamps are assigned explicitly during test data generation using `timedelta`.
## 2024-07-12 - CI failures due to Gradle version and script corruption
**Learning:** Duplicate plugin declarations in `build.gradle.kts` cause Gradle to fail with 'already requested' errors. Additionally, `gradlew` script can become corrupted with shell syntax errors (e.g., `Syntax error: "else" unexpected`) and needs to be replaced with a valid version from the official Gradle repository. Finally, building the Android project requires updating the Gradle wrapper to version 9.4.1 (in `gradle/wrapper/gradle-wrapper.properties`) to satisfy the minimum supported Gradle version required by the declared Android Gradle Plugins.
**Action:** Always check `build.gradle.kts` for redundant/duplicate plugins and remove them. If `gradlew` fails with syntax errors, re-download it from raw.githubusercontent.com. Ensure the Gradle wrapper version matches the requirements of the updated AGP.
